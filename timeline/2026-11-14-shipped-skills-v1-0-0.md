My own agent skills moved out of my dotfiles into [skills](https://github.com/TheClooneyCollection/skills), and [v1.0.0](https://github.com/TheClooneyCollection/skills/releases/tag/v1.0.0) is the first release. You can now install them without my setup: as a Claude Code plugin, a Codex plugin, or with `npx skills add TheClooneyCollection/skills`. The release also adds a `release` skill, which cut this release, and a CI check that keeps the skills, the plugin manifests and the README in step.
