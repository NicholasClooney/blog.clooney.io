I released [v1.2.0](https://github.com/TheClooneyCollection/skills/releases/tag/v1.2.0) of my [skills](https://github.com/TheClooneyCollection/skills). It ships two new skills: [`illustrate-post`](/timeline/2026-11-14-shipped-illustrate-post-skill/), which turns a post's images into a plan, hand-drawn SVG diagrams, image-model variants in a few styles and one gallery to pick from, and [`avp-mvd-alvr-stutter-resolver`](/timeline/2026-11-14-shipped-avp-mvd-alvr-stutter-resolver-skill/), which fixes Vision Pro stutter when Mac Virtual Display and ALVR run together. Every skill folder now also has a short README for people: what the skill does, why it exists, when to use it and what it needs.
